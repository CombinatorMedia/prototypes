# Prototypes

Interactive prototypes from my product design work, built in code so they can be clicked through rather than just looked at. Each one lives in its own folder and is published with GitHub Pages, so every prototype has a stable link I can share or embed in a case study.

| Prototype | Description | Link |
| --- | --- | --- |
| Player Discovery | A content discovery concept for a video player experience. | [Open prototype](https://combinatormedia.github.io/prototypes/player-discovery/) |

## How it's organized

```
prototypes/
  player-discovery/
    index.html      Self-contained build (React bundled into a single HTML file)
```

New prototypes get their own folder, which becomes `https://combinatormedia.github.io/prototypes/<folder>/`.
